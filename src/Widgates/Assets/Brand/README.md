# Morf artwork

Project artwork supplied by Mustafa Günay:

- `morf.ico`: native EXE icon, with 16, 24, 32, 48, 64, 128 and 256 pixel frames.
- `morf-64.png`: settings header.
- `morf-256.png`: window icon and repository logo.

Both build paths embed these assets. The application does not require loose artwork files at runtime.

The media launcher also embeds vendor icons for offline use. Apple Music and Spotify use their installed Windows icons when available.

- `apple-music.png` comes from [Apple Support’s Windows app artwork](https://support.apple.com/en-us/118290).
- `spotify.png` comes from [Spotify’s web app icon](https://open.spotify.com/favicon.ico).
- `youtube.png` comes from [YouTube’s web app manifest](https://www.youtube.com/manifest.webmanifest).
