## Changes

- Standard video PiP is the default without the gray Document PiP origin header. Advanced controls remain an explicit option; their browser-owned header remains visible. Changing mode affects the next opening. Standard mode pauses on either close or browser return; advanced mode has a separate return action that preserves playback.
- A YouTube MAIN-world metadata guard rejects recommendation metadata before publication to Windows. It retains the accepted main-video object, checks the watch URL against the main player and never recycles preview artwork. Navigation and advertisements are excluded from repair. This requires the companion extension.
- PiP opening clears an ordinary capsule click latch and stale swipe state, preserving explicit pinning. Released-pointer leave events cancel unfinished gestures and schedule collapse.
- Desktop following remains enabled by default. Ordinary window-location events no longer start virtual-desktop COM work. Cloak/uncloak and relevant foreground events request synchronization; observed failed transitions have at most two delayed retries. Only Morf's own window is moved. Browser PiP all-desktop pinning is not implemented through undocumented interfaces.
- Settings no longer suspend capsule hover, transport, volume-wheel handling or live visuals, and closing settings retains interactions performed while they were open.
- Notifications have an independent disclosure, short basic options, and collapsed application/Windows details. Disabled notifications have no interactive options. Music connections live under Media and sound. Shortcuts capture keys locally, allow clearing/resetting and remain drafts until Apply. Liquid Glass's independent transparency and existing rendering remain intact.
